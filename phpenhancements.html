Application management

Data Source application management demonstration.

Assignment 3 implementation

The private academic version processes applications in PHP and stores them in MySQL using mysqli prepared statements. The portfolio reproduces the workflow with fictional JSON records and browser storage.

1. Sortable HR application results

Managers can filter by job reference, first name, last name or both names, then sort by EOI number, job reference, applicant name, status or submission time in either direction. PHP restricts sort columns and direction to allowlists and binds filter values. The portfolio performs equivalent operations locally.

Explore application management.

2. Protected manager accounts

The PHP implementation includes invitation-based registration, unique usernames, a password rule, password hashing, session regeneration on login and a five-minute account lock after three failed attempts. Signing out destroys the session. Every manager request checks the session, and changes require a CSRF token. The static portfolio has an openly accessible demonstration screen and provides no authentication or access control.

Shared presentation

header.inc, menu.inc, banner.inc and footer.inc reuse the Assignment 2 design in PHP. Matching banners share one size, typography and layout. The portfolio includes the corresponding rendered HTML for static hosting.
