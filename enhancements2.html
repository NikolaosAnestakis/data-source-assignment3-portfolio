Enhancements2

Helpful interactions built on the Data Source design.

1. Live application completion

Open the application form and fill its required fields. A progress meter updates after input or selection changes. It includes valid age and postcode checks and adds the Other skills description when selected.

Implementation: querySelector, input/change listeners and the native progress element in scripts/enhancements.js. This is guidance only; the private PHP endpoint performs the authoritative validation. Reset recalculates completion.

2. HamburgerElegant responsive navigation

Resize the viewport below 1201px, then activate the animated navigation button. A full-screen drawer reveals the site links with a staggered entrance. Close with its button, Escape, or by selecting a link. Keyboard focus stays within the native modal dialog; closing returns focus to the menu button.

Implementation: external styles/hamburger.css and scripts/enhancements.js. The two-stage hamburger-to-cross animation and drawer reveal are adapted from Nikolaos Anestakis, HamburgerElegant/menudrawer.html (source blob 6f9f00aa9e1f98984213f942c32d90e5dcdca409). No JavaScript libraries are used. Reduced-motion preferences are respected. With JavaScript unavailable, the original navigation remains visible.

Try the responsive navigation.

Additional feature: optional application timer

On the application page, enable the 20-minute timer. A visible warning appears with one minute left. Add 20 minutes using the warning button, or disable the timer at any time. Expiry returns to Home. The timer is off by default and Reset disables it.

Implementation: a Date.now deadline and setInterval in scripts/enhancements.js; the warning uses role=alert. It does not save an unfinished application. The extension button can be used repeatedly.
