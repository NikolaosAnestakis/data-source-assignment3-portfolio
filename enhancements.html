Responsive Design Enhancement

Fluid widths and layouts that resize or reflow are part of the assignment baseline. This enhancement is the additional breakpoint-specific CSS that structurally adapts components for smaller viewports rather than simply making them narrower.

  • max-width: 900px provides tablet adaptations.
  • max-width: 48rem provides mobile adaptations.
  • max-width: 600px provides small-mobile Jobs refinements.

Home Services

Desktop: the introduction and service items use a multi-column floated layout. Mobile: the floats are removed and each item becomes a full-width stacked block. The Join Our Team section is another implementation example: its side-by-side image and content become a vertical mobile layout.

View the responsive Home page 

@media screen and (max-width: 48rem) {
  .services-intro {
    float: none;
    width: 100%;
    padding-right: 0;
  }

  .service-item {
    float: none;
    width: 100%;
    padding: 0;
  }
}

Jobs

Desktop: job listings and the supporting aside use a 75/25 layout. Tablet: both become full-width stacked sections. On small-mobile displays, job metadata becomes vertical and each Apply button becomes full-width.

View the responsive Jobs page 

@media screen and (max-width: 900px) {
  .job-listings,
  .jobs-aside {
    float: none;
    width: 100%;
  }
}

@media screen and (max-width: 600px) {
  .job-meta li {
    float: none;
    margin-right: 0;
    margin-bottom: 0.8rem;
  }

  .job-meta li:last-child {
    margin-bottom: 0.95rem;
  }

  .job-apply .button {
    width: 100%;
    text-align: center;
  }
}

Application Form

Desktop: form cards and form rows use multi-column layouts. Mobile: the floats are removed and card content, options and form groups become full-width blocks.

View the responsive application form 

@media screen and (max-width: 48rem) {
  .application-form .form-card-heading {
    float: none;
    width: 100%;
  }

  .application-form .form-card-content,
  .application-form .form-options {
    float: none;
    width: 100%;
  }

  .application-form .form-row .form-group,
  .application-form .form-row-three .form-group,
  .application-form .form-row .form-full {
    float: none;
    width: 100%;
  }
}

About Personal Details

Desktop: the photograph appears beside the personal details. Mobile: the photograph moves above the full-width details list and is centred for the narrower viewport.

View the responsive About page 

@media screen and (max-width: 48rem) {
  .student-photo {
    float: none;
    width: 100%;
    text-align: center;
  }

  .student-details {
    float: none;
    width: 100%;
  }
}

How to assess this enhancement

Open the linked examples and resize the browser across 900px, 48rem (approximately 768px) and 600px. The components change structure at these breakpoints rather than only resizing.
